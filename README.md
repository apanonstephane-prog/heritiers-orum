# Les Héritiers d'Orun — Acte I

Beat 'em up 2.5D afro-futuriste (Phaser 3.80, HTML/JS statique, sans build).
Visuels générés avec Higgsfield, animés image par image.

- Jouer : ouvrir `index.html` via un serveur statique (ex. `npx serve .`).
- Clavier : flèches/ZQSD, J frappe, K saut, L Tempête, Maj esquive. Tactile : joystick + boutons.
- Intégration sur un site : `<iframe src="https://<projet>.vercel.app" allow="autoplay; fullscreen" style="width:100%;aspect-ratio:16/9;border:0"></iframe>`
